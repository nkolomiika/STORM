# User management

Only administrators manage workspace users under sidebar **Members**. There is no public registration. Workspace membership and membership of individual projects are separate.

## Inviting a user

Press **Invite member**, enter the email, choose the workspace role (User/Admin) and project role (Lead/Pentester), then send the invitation.

The recipient opens the link and chooses their own username and password. Username availability is checked during activation; temporary passwords are not used.

## Pending invitations

Pending invitations can be resent or revoked. Revocation asks for confirmation. An unactivated invitation is not an active user account.

## Roles

Admin grants platform administration and access to all projects. User grants access to projects where the person is a member. Lead grants team/project-card management within those projects; Pentester is the ordinary project role.

## Editing and blocking

The edit action changes account and project roles. Usernames are fixed; administrators do not change another person's email through this form.

The delete action blocks access while preserving project data, findings, and notes. To restore a blocked person, send a reactivation link and let them complete the account-return flow.
