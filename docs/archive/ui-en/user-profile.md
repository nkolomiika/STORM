# Profile and security

Open **Profile** from your name in the top-right menu. Its sections are **Account**, **Security**, **API & Automation**, and **Customizing**.

## Account

Upload a PNG, JPEG, WEBP, or GIF avatar up to 5 MB. It appears beside your name and in member lists. The identity card shows your username, email, role, and ID as read-only information.

## Security

Set up two-factor authentication using a TOTP authenticator: scan the QR code or enter its secret manually, then confirm a six-digit code. Subsequent sign-ins require the authenticator code in addition to the password.

Disabling 2FA requires your account password. Session changes follow the account security workflow. You can also change your account password in this section.

## API & Automation

Create API keys for CI, bots, and agents. Any user can create a token within their current project permissions. See **Tokens and permissions** for scopes, project selection, expiry, and revocation.

## Customizing

Choose light or dark theme and English or Russian interface language. Preferences are saved in this browser. The saved language also applies to sign-in and account-link screens.
