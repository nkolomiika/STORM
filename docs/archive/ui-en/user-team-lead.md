# Team lead workflow

The global **Lead** project role grants management capabilities only inside projects where that user is a member. Administrators assign this role in workspace **Members**. Project creators and administrators have the same project-management capabilities.

A lead remains an ordinary workspace user; the role does not grant access to every project.

## Managing project members

Open the project's **Members** section, press **Add member**, search an existing workspace user, and confirm. The added person gains access and receives a notification. Remove a member using the delete action on their row.

Leads add existing workspace users. Only administrators can invite new workspace users or change account roles.

## Editing the project

Leads can edit the project name, description, status, and start/end dates from the project card or list-row edit action.

## Administrator-only operations

Leads cannot create or delete projects, invite workspace users, or assign roles. See the administrator documentation for those operations.
