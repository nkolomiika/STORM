# Project notes

Notes hold methodology, recon results, drafts, and shared assessment material. Open **Notes** to see note cards.

## Creating and editing

Create a note, enter its title and Markdown content, then press **Save changes**. Click your own note to open its editor; other authors' notes open read-only. **All notes** returns to the list. Your note's delete action is available on its card.

The editor formats Markdown as you type. Paste screenshots to insert images. Click an image to show corner resize handles; click elsewhere to hide them. Drag an image through the text and drop it at the insertion point to move it.

**Save changes** is disabled until the title or content changes. Successful saves keep you on the note page. **Cancel** discards the editing session.

Only the note's author can edit or delete it. Read-only notes use the same viewer styling.
