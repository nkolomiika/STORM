# Projects

Only administrators create and delete projects. Ordinary users and leads work inside projects to which they have access.

## Creating a project

Open **Projects → New project**, enter a name and the required **AppSec ticket**: select an APPSEC task or paste its URL. Description and dates are optional. The creator is automatically added to the project's members in the same transaction. Add the remaining team from the project **Members** section.

## Editing

Administrators, project creators, and leads who belong to the project can edit its name, description, status, and dates. Use the project-row edit action. The User Projects chapter describes the available statuses.

The APPSEC ticket can be replaced but cannot be cleared. Existing projects without a ticket must supply one before saving the form or exporting vulnerabilities to STS.

## Deleting

Only administrators can delete a project. The row action opens a confirmation dialog. Deletion removes related project data and cannot be undone through the UI.
