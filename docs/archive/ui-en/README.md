# Архив английской справки интерфейса

Английские статьи раздела Docs временно архивированы по решению владельца проекта 15 ноября 2026 года. Все 16 статей перенесены сюда без изменения содержимого. Они не импортируются frontend и не включаются в сборку приложения.

Действующая справка хранится в `frontend/src/storm/docs` и всегда показывается на русском, независимо от языка интерфейса. Русскими остаются оглавление, поиск, подписи и содержимое статей; глобальная языковая настройка пользователя не меняется.

Архив не поддерживается автоматически в актуальном состоянии. При возврате английской версии сначала сверить статьи с действующей русской справкой, затем восстановить импорты/выбор языка и обновить проверки `StormDocs`/`Localization`. Одного переноса файлов обратно недостаточно: русская локаль справки явно закреплена в компоненте.
