# Одноразовый архив STORM

`backend/scripts/one_time_download.py` — самостоятельный HTTP-сервис стандартной библиотеки Python, не требующий запуска STORM, PostgreSQL или RabbitMQ. Все его функции документированы в исходнике. Он предназначен для временной выдачи подготовленного архива через HTTPS.

## Поведение

- Секретный URL сразу скачивает архив без промежуточной страницы и кнопки. Первый GET расходует ссылку; HEAD возвращает только метаданные и не расходует скачивание.
- Создание постоянного маркера через `O_CREAT | O_EXCL` разрешает ровно одну попытку, в том числе при конкурентных GET-запросах. POST не поддерживается.
- Автоматический предпросмотр, если он выполняет GET, тоже расходует ссылку. Не передавайте URL сервисам проверки или предпросмотра.
- После начала скачивания ссылка считается использованной. Даже при обрыве повтор запрещён; для новой попытки администратор должен подготовить новую выдачу.
- После выдачи или обрыва архив удаляется. Постоянный маркер сохраняется, поэтому перезапуск сервиса не открывает повторный доступ.
- Запросы диапазона не поддерживаются. Неверные URL не получают архив. Ответы не кешируются, страница не использует внешние ресурсы, секретный путь не печатается в access-лог.

## Подготовка

Архив создаётся из проверенного коммита с `git archive`. В него входят отслеживаемые исходники, документация и примеры конфигурации; локальные `.env`, SSH-ключи, дампы БД и ignored-файлы не включаются.

Конфигурация должна храниться в закрытом каталоге с правами 0700, сам файл — 0600. Например:

```json
{
  "archive": "/opt/storm-download/storm.tar.gz",
  "token": "СЛУЧАЙНАЯ_СТРОКА_ИЗ_secrets.token_urlsafe_32",
  "consumed_file": "/opt/storm-download/download.used",
  "host": "127.0.0.1",
  "port": 8765,
  "commit": "ПОЛНЫЙ_HASH_КОММИТА",
  "sha256": "SHA256_АРХИВА"
}
```

Токен должен содержать 32–128 URL-safe символов; пример выше — описание, а не рабочий токен. Сгенерируйте значение через `secrets.token_urlsafe(32)`. Архив, конфигурацию и маркер нельзя помещать в общедоступный document root.

```bash
python3 one_time_download.py --config /opt/storm-download/config.json
```

По умолчанию сервис слушает loopback за HTTPS-прокси. Для прямого TLS добавьте `certificate` и `private_key` с путями к существующим файлам сертификата/ключа и подходящий `host`/`port`. Закрытый TLS-ключ не является SSH-ключом. Публичный доступ следует открывать через TLS; действующие веб-сервисы останавливаются отдельно после проверки их назначения.

## Проверка перед выдачей ссылки

`tests/test_one_time_download.py` использует отдельный тестовый архив и проверяет HEAD без расходования ссылки, прямое скачивание GET, шесть конкурентных запросов, повтор после перезапуска, обрыв загрузки, отсутствие архива и отклонение диапазонов. Рабочую ссылку проверяйте только HEAD: GET необратимо израсходует её.
