# Проекты

Создание и удаление проектов — операции администратора. Обычные пользователи и лиды работают внутри уже созданных проектов, но не создают и не удаляют их.

## Создание проекта

1. Откройте раздел **Projects**.
2. Нажмите **New project**.
3. Укажите название. При необходимости выберите **AppSec ticket** из поиска APPSEC или вставьте ссылку. Тикет и даты начала/окончания необязательны.
4. Сохраните.

Создатель автоматически становится участником нового проекта. После создания добавьте остальных участников (это может делать и лид/создатель) и, при необходимости, назначьте статус проекта.

## Редактирование карточки

Карточку проекта — название, **статус** и даты — может править администратор, лид проекта и его создатель. Редактирование открывается кнопкой правки в строке проекта. Статусы проекта перечислены в главе «Проекты» документа **Пользователь**.

APPSEC-тикет можно заменить или очистить. Для экспорта уязвимостей в STS нужны тикет, исполнитель и затронутые версии проекта. При нехватке данных кнопка экспорта покажет уведомление со списком недостающих полей.

## Удаление проекта

Удаление проекта доступно **только администратору** (кнопка удаления в строке проекта, с подтверждением). Удаление необратимо и уносит связанные с проектом данные, поэтому выполняйте его осознанно.
