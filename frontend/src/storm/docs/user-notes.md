# Заметки проекта

Заметки — это общие материалы проекта: методология, результаты разведки, черновики находок и любые совместные записи. Заметки живут во вкладке **Notes** проекта и отображаются списком карточек.

## Как работать с заметками

**Создать заметку:**
1. Откройте проект → вкладка **Notes**.
2. Нажмите кнопку создания заметки.
3. Введите заголовок и содержимое, нажмите **Save changes**.

Текст заметок пишется в **Markdown** — редактор форматирует его по ходу набора. В заметку можно вставлять изображения.

Таблицу можно вставить как Markdown. Она отображается таблицей в редакторе и
при просмотре, сохраняется вместе с заметкой и восстанавливается при открытии:

```markdown
| Хост | Результат |
| --- | --- |
| api.example | Проверен |
```

У широких таблиц появляется горизонтальная прокрутка. Поддерживается
форматирование внутри ячеек. Символ вертикальной черты в тексте ячейки
экранируйте как `\|`.

**Редактировать.** Клик по своей заметке открывает её **сразу в редакторе** — правьте заголовок и текст и сохраняйте кнопкой **Save changes** внизу; кнопка **Cancel** рядом отменяет правки. Кнопка **All notes** сверху возвращает к списку. Удалить заметку можно из списка (корзина у своей заметки).

Пока изменений нет, **Save changes** бледная и недоступна. После сохранения
редактор остаётся на той же странице. У изображения по нажатию появляются
угловые маркеры размера; нажатие вне изображения скрывает их. Изображение
можно перетащить в другое место текста.

> Редактировать и удалять можно **только собственные** заметки. Чужая заметка открывается в режиме **Read only** — в том же оформлении, но без возможности менять.
