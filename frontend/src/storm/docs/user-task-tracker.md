# Task Tracker (задачи)

Раздел **Tasks** в сайдбаре Workspace — это read-only витрина задач из **Task Tracker** (Works, пространство APPSEC). Он показывает актуальные задачи трекера прямо в Storm, чтобы не переключаться между системами.

> Если интеграция с Task Tracker не настроена, раздел пуст и показывает соответствующее сообщение. Подключение задаётся на уровне деплоя (переменные окружения).

## Список задач

- **Вкладки Active / Closed** — делят задачи на активные и завершённые. В **Closed** попадают завершённые статусы, а также задачи на паузе (paused).
- **Сортировка** — по дате обновления (последние обновлённые сверху); порядок можно переключать.
- **Поиск** — по названию задачи (поле «Filter tasks by title…»).
- **Статусы** в таблице локализуются и подсвечиваются по тем же правилам, что и статусы находок: ожидание — серый, в работе — синий, завершено — зелёный.

Колонка **Key** — ссылка: клик по ключу открывает сам тикет в Task Tracker.

## Карточка задачи

Клик по строке открывает карточку задачи: слева — ключ, заголовок и описание; справа панель **Details** — статус, тип, приоритет, исполнитель, все затронутые версии, постановщик и даты. Кнопка **Open in Task Tracker** открывает задачу в трекере.

## Создать проект из задачи

В каждой строке таблицы есть действие **«+»** (по центру колонки Actions):

- Нажатие загружает полную карточку и открывает форму **создания проекта** с заполненными **AppSec-тикетом**, **исполнителем** и **всеми затронутыми версиями**. Если этих необязательных данных в тикете нет, поля остаются пустыми. Задайте название и сохраните; перенесённые данные можно изменить.
- Если проект с этим тикетом **уже существует**, вместо «+» показывается иконка-ссылка на этот проект — по ней можно сразу перейти в него.

Так задача из трекера за один клик превращается в проект Storm, уже связанный с исходным тикетом.

В локальном стенде с демо-тикетами появляется пометка **Демо-данные**. Варианты с двумя/тремя версиями позволяют проверить весь список; демо-режим не отправляет данные во внешний Task Tracker.
