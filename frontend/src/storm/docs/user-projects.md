# Проекты

Проект — верхнеуровневый контейнер одного проекта работ (engagement). Внутри проекта живут его хосты и активы, уязвимости, заметки и участники. С проекта начинается любая работа в Storm.

## Список проектов

Раздел **Projects** в сайдбаре показывает все проекты, к которым у вас есть доступ. Наверху — плитки со сводкой (активные и архивные проекты, число открытых уязвимостей, количество хостов). Список делится на вкладки **активных** и **архивных** проектов.

> Создавать проекты могут **lead** и **admin**. У обычного пентестера кнопки создания нет. Удалять проект могут администратор, его создатель и лид, состоящий в проекте; у остальных участников корзина скрыта.

Чтобы открыть проект, нажмите на его строку в списке.

## Статусы проекта

У каждого проекта есть статус, отражающий стадию работ:

- **Active** — работы идут.
- **Freeze** — работы приостановлены (проект не активен, но и не завершён).
- **Handover to dev** — передача результатов разработке.
- **Recheck** — повторная проверка (ретест) уязвимостей.
- **Completed** — работы завершены.
- **Archived** — проект в архиве.

Статус **не блокирует** редактирование. Любой участник может править карточку проекта: кнопкой **Редактировать** или карандашом в списке. Создание, удаление и управление участниками проверяются отдельно.

У связанного с APPSEC проекта статус автоматически обновляется из тикета: при загрузке списка/карточки задач и фоново раз в минуту. Известные состояния сопоставляются со стадиями STORM; неизвестное состояние не меняет проект. При недоступности Task Tracker сохраняется последнее состояние. Привязка, исполнитель, компоненты и версии автоматически не перезаписываются.

## Поля AppSec и Task Tracker

В форме проекта есть поля для связи с Task Tracker (Works). Создают проекты администратор и лид, редактируют — также обычные участники:

- **AppSec-тикет** — необязательная связь проекта с задачей APPSEC: вставьте URL тикета или начните вводить название и выберите задачу из Task Tracker. Ссылка на тикет затем подставляется в отчёт («по задаче …»).
- **Исполнитель** — человек, который попадёт в создаваемый тикет (поле assigned_to). Поиск по ФИО или логину: начните вводить — выпадут подходящие люди (в списке показывается ФИ — фамилия и имя).
- **Затронутые версии** — можно выбрать несколько версий Works. Все выбранные версии сохраняются; удалить отдельную можно крестиком рядом с её названием. При создании проекта из Tasks переносятся все версии и исполнитель исходного тикета.
- **Компонент** — компонент Works (доступен при включённой интеграции Works).
- **Код продукта** — значение справочника STS с поисковой подсказкой. При
  создании из Tasks код продукта, компоненты и версии переносятся из полной
  карточки APPSEC.

> После успешного создания проекта вы сразу попадаете на его страницу. Обязательно только **Название**; все поля связи с Task Tracker необязательны для сохранения. В интерфейсе и экспорте Task Tracker названия версий сохраняются целиком. В отчёте СЗИ убирается только название продукта: `Platform V Stack 1.0.2-beta.2` → `1.0.2-beta.2`.

## Разделы внутри проекта

Открыв проект, вы увидите его вкладки:

- **Overview** — карточка проекта: название, даты, сводка.
- **Recon** — инфраструктура цели. Внутри переключаются три вида: **Hosts** (хосты), **IPs** (IP-адреса) и **Endpoints** (HTTP-эндпоинты). Подробно — в главе «Хосты и активы».
- **Vulnerabilities** — найденные уязвимости проекта. См. главу «Уязвимости».
- **Notes** — заметки проекта. См. главу «Заметки проекта».
- **Members** — участники проекта. Просмотр доступен участникам; управление составом — лиду/создателю/админу (см. главу «Работа тимлида»).
- **Activity** — лента активности: кто и что менял в проекте.

## Лента активности

Вкладка **Activity** показывает хронологию изменений по проекту: заведение и правки уязвимостей, изменения активов, добавление участников и т.д. Лента видна всем участникам проекта и помогает быстро понять, что происходило, пока вас не было.

Для экспорта уязвимостей в STS заполните тикет APPSEC, исполнителя, затронутые
версии, код продукта и компоненты проекта. Пока данных не хватает, кнопка
экспорта серая и недоступна; наведение показывает подсказку о необходимых
полях. Создание и редактирование проекта доступны без этих данных. Если
ссылка на APPSEC отсутствует, в отчёте будет жёлтая подсказка «Заполните ссылку
на APPSEC-тикет». После отмены создания из Tasks обычная форма нового проекта
открывается пустой.
